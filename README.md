# Eneba front page recreation

Vite + ElysiaJs

Front:
- Vite
- React
- React Query
- React router
- zustand

Back:
- Node.js
- ElysiaJS
- PrismaORM
- Neon database (PostgreSQL)

Can be launched using docker compose for backend will need neon database keys, but there is data seeder prisma/seed.js which adds 8 elements.
